# OpenClaw Integration

Production OpenClaw integration is not available in pCodex `0.3.0b1`.

The repository contains OpenClaw detection, authority policy, fixtures, and research evidence. Those surfaces do not constitute an installable, discoverable, repairable, removable, or qualified product adapter. The planned `pcodex integrate openclaw` lifecycle is therefore not a supported command and must not appear in executable setup instructions.

G4 remains open until the product has:

- a receipt-bound preview, install, status, repair, disable, and uninstall lifecycle;
- immutable workspace-root binding and traversal/symlink containment;
- installed-artifact helper resolution on macOS and Linux;
- MCP/tool negotiation, invocation, cancellation, shutdown, and sensitive-error proof;
- a frozen 20-task OpenClaw acceptance set spanning investigation, modification, repair, authority reconciliation, Unreal, Blender, and nested executors;
- zero unresolved P0/P1 findings.

Until G4 passes, use the general pCodex workflow only. Do not describe observer profiles, benchmark harnesses, templates, or generated proof artifacts as the production OpenClaw adapter.
