# pCodex Privacy Notice

pCodex is a local-first technical beta. It reads eligible repository metadata
and files to produce bounded context guidance. Public receipts exclude raw
prompts, source bodies, secrets, model packets, environment values, and private
absolute paths. Repository paths, local configuration, detailed hashes, and
private evidence receipts remain local unless the user deliberately shares
them. pCodex does not provide a hosted service in this beta.

Optional Codex plugin and MCP integration is disabled until explicitly applied.
MCP activation does not change the repository eligibility or receipt privacy
rules. See `docs/SECURITY_MODEL.md` and `docs/NO_WRITE_CONTRACT.md` for the
technical boundaries.
