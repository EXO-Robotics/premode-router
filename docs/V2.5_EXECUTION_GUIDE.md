## What is implemented

### Repo map foundation

```bash
premode map
premode map --json
premode map --out .premode/out/repo_map.json
```

Implemented capabilities:

- deterministic `repo_map_sha256`
- per-file SHA-256 hashes
- Python AST imports/classes/functions/methods/pytest tests
- lightweight Rust, Swift, JS/TS symbol extraction
- Markdown headings
- JSON/TOML/YAML top-level keys
- related-test hints
- deterministic import/reference edges where safe
- manifest-derived entrypoints from Cargo, package.json, pyproject, and Package.swift
- no file contents stored in repo-map output

### Minimal compile integration

```bash
premode compile "Find the right files for a safe Rust CLI patch" --use-repo-map --json
```

Implemented capabilities:

- `repo_map_summary` in compile output
- `impact_map` in compile output
- CLI/argument/flag prompts can point to manifest-declared source entrypoints
- repo-map relevance can raise relevance, but does not promote files to full text by itself
