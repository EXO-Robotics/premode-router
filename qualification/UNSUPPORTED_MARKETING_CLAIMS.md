# Unsupported Marketing Claims

The following claims are not supported by this study:

- B0 reduces complete-task tokens.
- B0 preserves or improves task success across Qwen, Gemma, and OSS.
- B0 reduces unnecessary file exploration across model families.
- B0 has passed an 80–100-task qualification panel.
- B0 has passed a final held-out release gate.
- B0 is locked for version 0.3.0b1 on the basis of this study.
